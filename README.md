# ImageProcessing-Benchmarking
In this repository, you will find the following contents:

Script Folder: Contains individual README files offering guidance for each script. These scripts are utilized for the analyses in the study titled "A benchmarked comparison of software packages for time-lapse image processing of monolayer bacterial population dynamics".

Raw-Images Folder: Houses all datasets utilized as raw images and inputs.

Pixel-Classification Folder: Stores data associated with the output from ilastik, used as input for FAST and CP.

Ground Truth Folder: Contains data related to reference masks, serving as segmentation ground truth, along with data for tracking ground truth.

Individual Package Folders: Each package has a dedicated folder where outputs for each dataset are stored. Inside these, there's a subfolder named "Analyses", which includes tracking plots for each package and post-processing analyses.
